## What stays the same

- The self-hosted build is the whole product. There is no licence key and no feature that only the hosted
  service has.
- The source code is AGPL-3.0-only.
- Your data can leave: export a household as JSON at any time, and import it into a self-hosted instance. See
  [Glideworth JSON](/docs/importing/glideworth-json/).

## What this page does not say

It does not promise an opening date, uptime, or certifications. Those will be stated where they are true.
