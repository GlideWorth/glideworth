# Glideworth feature parity

A feature-by-feature matrix of what Glideworth implements. The feature list was drawn up in November 2026 from
the public documentation of ProjectionLab, version 4.6 at the time, because it is a widely used planner in the
same category. Glideworth is not affiliated with ProjectionLab, and this page makes no statement about what
ProjectionLab or any other product does today. For each feature we looked for the **code**
that does it: schema in `packages/core/src/schema`, engine in
`packages/core/src/engine`, tax in `packages/core/src/tax`, solvers/insights/stochastic under
`packages/core/src`, importers in `packages/importers`, the API in `apps/api`, the UI in `apps/web/src`. No earlier
status report was used.

- **Implemented**: code exists that models or exposes the feature as described.
- **Partial**: some of it exists; the note says what is missing or approximate.
- **Missing**: no code. Where the public documentation did not confirm a feature, the row says `UNCONFIRMED`.
- **Removed**: was built, then taken out; the note gives the date and the reason. Not counted as implemented.

"Implemented" means the code is there and reachable (schema field, engine phase, UI screen or route); it is
not a line-by-line audit of every edge case, and tax tables are for stated tax years
([USER-GUIDE](USER-GUIDE.md#4-limitations)). Paths are relative to the repository root.

## Summary

210 features checked: **167 Implemented, 35 Partial, 5 Missing, 3 Removed** (moving country, departure tax and OFX/QIF import, removed on 2026-11-19 for lack of evidence of demand). A few features on the list could not be confirmed from public documentation (marked UNCONFIRMED); they are counted only where Glideworth has a row for them.
